2027 LINK PRAY ROOM — GitHub 업로드용 v1

이 버전은 홈 화면을 사이트 제목 → 말씀 → 기도하러가기 → 기도시간 순서로 표시합니다.
회원가입/로그인, 마이페이지, 관리자 기능, 오늘 전체 기도시간, 관리자 오늘 기도자 목록, 흰 배경 아이폰 홈 화면 아이콘은 최신 기능을 유지합니다.

압축을 풀고 안의 파일과 폴더를 GitHub 저장소 최상위에 올립니다. Netlify는 netlify.toml에 따라 public 폴더를 배포합니다.
Netlify 환경변수: SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY
SUPABASE_SERVICE_ROLE_KEY는 비공개로 보관하고 GitHub에 올리지 마세요.
Supabase SQL은 별도 linkpray-supabase-sql.zip의 README.txt를 확인하세요.
