2027 LINK PRAY ROOM — GitHub 배포 파일

GitHub에 이 압축파일의 안쪽 파일과 폴더를 저장소 최상위에 올립니다.
Netlify 설정은 netlify.toml에 있으며 publish 폴더는 public입니다.
iPhone 홈 화면용 apple-touch-icon과 PWA 아이콘은 새 파일명으로 된 흰 배경 로고입니다.

Netlify 환경변수
- SUPABASE_URL
- SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY (비공개로 보관하고 HTML/GitHub에 넣지 마세요)

기존 Supabase 프로젝트 SQL은 별도 Supabase SQL 압축파일 안내를 참고하세요.
JavaScript, CSS, HTML은 읽기 어렵도록 압축되어 있으나 브라우저 개발자 도구에서 완전히 숨겨지지는 않습니다.
